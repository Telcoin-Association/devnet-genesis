The harness's MDBX knobs must stay unset and must not be required: `BENCH_NODE_DB_SYNC_MODE` (`--db.sync-mode` is an MDBX flag), `BENCH_NODE_EVICT_MDBX` / the `evict-mdbx` host step (targets `db/mdbx.dat`). New optional flags exist (`--db.gap-fill`, default `auto`; `--db.max-size` is now a reservation): the bench passes neither; record the node's effective values in the manifest if the node logs them.
