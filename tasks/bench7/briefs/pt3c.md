## Background

The fix (brief `tasks/bench7/briefs/pt3a.md`; the unit's notes `tasks/checkpoint-bench7-PT-3a.md`): with `quorum_exec_block` on, a proposer names an execution block a quorum has shown it executed, floored 8 block-producing outputs behind its own tip and never before the epoch's opening block; `quorum_exec_block_starved_rounds` = 0 is the always form, N > 0 the adaptive form (the own tip until an own header is cancelled, then the quorum-backed block for a window that doubles, reset after 64 consecutive certified tip headers).
Its review and security evaluation (`tasks/bench7/review/05-quorum-exec-block-report.md`: read V1, V2, V3, I1 and the answer to question 8 in full, with their evidence) approved it with follow-ups. Bench 7 runs both forms on a fleet to decide between them, so the adaptive form must be the form that would be upstreamed: V1 is fixed before the image.
