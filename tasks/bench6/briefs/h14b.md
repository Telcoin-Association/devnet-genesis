## Why
Run 1 of bench 6 is a sequence of arms; each arm flips node switches and runs blasts started by hand. Two things changed
under the analysis tools since they were written: (1) a hand-run blast now leaves a `blasts[]` entry like a scripted one,
failed ones included with their rc (unit H13; `benchmark/arms/MANIFEST-FIELDS.md`), and (2) the node units landed, with log
fields and counters the arm summary was designed to read but could not see yet. The tools are what turns a paid fleet run
into a verdict per arm, so each must read what the run really writes — and a failed blast must never be measured.

5. **Storage (mdbx-advice arm and every arm's control):** from `persisted output`: whether prefault was on
   (Δ`page_prefault` ≈ Δ`mdbx_last_pgno` per persist), the amplification per arm = device write bytes ÷ ((`page_newly` +

7. **Admission-bound arm:** refused requests (`tn_reth_rpc_admission_refused_total` or the generator's `pool_full` class),
