## What the test is for

The removal branch deleted `test_mixed_switch_fleet_is_one_chain` (at `git show 500e21afa:crates/e2e-tests/tests/it/exec_block.rs`, from about line 520), which showed that validators that name their own tip and validators that name an older block (one a quorum of voters has executed) form one chain. After the removal every node of this tree names the quorum's block, so the only mixed fleet left is old binary beside new binary. The claim the pull request wants to make: **a voter running `main`'s binary votes for a header of this tree that names an execution block older than the proposer's own tip.** `make test-upgrade` did not show it (the rolling test slows no node and reads no `exec_basis`).

It SKIPS when the previous binary has no hook string.
