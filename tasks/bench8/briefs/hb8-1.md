4. The kill's offset. With `BENCH_CHAOS_TIMING=epoch` (`benchmark/config.sh:460-469`, `benchmark/benchmark-blast.sh`), the kill of validator-05 came 817 s into the load blast's mixed phase in one bench 7 run and 1,121 s in the other. Bench 8 reads the first 817 s before the kill, so a kill EARLIER than 817 s would spoil a run. Read how the epoch timing picks the moment and state the earliest and latest offset it can produce. If it can come before 817 s: add ONE knob (name it in the `BENCH_CHAOS_*` family) that holds the kill back until at least N seconds of the mixed phase have passed, unset = today's behaviour byte-identical (test), and set it to 817 in the four launch files. If it cannot: say why, and add nothing.
