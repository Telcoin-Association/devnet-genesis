# B8-3 — the author's side of a vote round: when each vote arrived

Common brief: `tasks/bench8/briefs/b8-common.md`. Skills: `tn-domain-consensus`. Worktree `/home/drtnarg/coding/telcoin/tn-b8-bench` (after B8-1). Checkpoint `tasks/checkpoint-bench8-B8-3.md`.

Bench 7 knew when a header was proposed and when its quorum was reached, not when each vote reached the author. A far validator's quorum forming last could not be split into "its requests arrive late", "the voters answer late" and "the answers travel long".

Read `crates/consensus/primary/src/certifier.rs` (the vote round: where requests go out near `:382-440`, where a vote or an error comes back, where the round ends in a certificate, a cancel or a timeout) and `crates/consensus/primary/src/aggregators/votes.rs` (`append`, the `quorum reached` line near `:80`). Find the line(s) bench 7's analysis parsed for a round's end (`quorum reached` with its fields, and whatever is logged when a header is given up).

Add, on the line that ends a vote round (certified or given up; if the two ends log different lines, on both; if a given-up round logs none, add one line `vote round ended` with `outcome`):
- `vote_arrivals`: for every answer received before the round ended, in arrival order, the voter and the milliseconds since the round's requests were sent, compact and bounded at the committee size (see the common brief), e.g. `03:41,07:44,…`.
- `vote_errors`: the same for answers that were not votes, with a short outcome code (`behind`, `timeout`, `missing_parents`, `too_old`, `other`: use the error kinds the code has; list them).
- `votes_at_end`: how many votes the round had when it ended, and `stake_at_end` if the aggregator holds it.
Votes that arrive after the round ended are not this unit's (say whether the code drops them silently or logs them).

Keep the time base explicit: milliseconds since when (the header's `created_at_ms`? the moment the requests were spawned?). Use a monotonic clock for the differences and say which instant is zero.

Tests: a unit test of the rendering (order, bound, both lists), and one on the crate's certifier test harness that a round with one refusing voter logs it under `vote_errors`.

Hand back as the common brief says, with one rendered line of a certified round and one of a given-up round.
